# Product

<!-- impeccable:product-schema 1 -->

## Platform

web (local app, desktop first, must work at phone width)

## Users

Built for a hackathon but held to real-product standards. Primary user: a solo creator who wants a finished,
narrated short video for TikTok / YouTube / Reels without animating anything themselves. They type a
topic or rough idea, then only decide and approve at each step.

## Product Purpose

Studio turns a topic into a finished, narrated 2D video. Five approval-gated stages: Ideas, Script,
Storyboard, Voice, Render. Claude Code does the writing and coding, ElevenLabs the voice, Remotion the render.
Success: a video worth posting, with the user in control of every creative decision.

## Positioning

Runs on the creator's own Claude Code locally; every stage is visible, editable and approved, and the
video is drawn in code (not generated footage), so it is consistent, re-renderable and safe.

## Capabilities and constraints

- Visual style choice (Cartoon, Flat 2D, Paper cut-out, Comic ink, …). Only Flat 2D (Winter Lake pack)
  renders today; the others guide Claude through short style notes in the skills.
- Output format choice: 9:16, 16:9, 16:10, 1:1, 4:5 and custom sizes, with presets for TikTok, YouTube,
  Shorts, Reels.
- Video length 20-180 s.
- Inspiration: the user drops rough idea fragments and Studio builds a story from them.
- Survival-safe topics only (see AGENTS.md hard rules). Costs shown are estimates, "not billed".
