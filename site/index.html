How it works

Five steps. You call every cut.

Each step stops and waits for you. Edit a line, pick another idea, rebuild a shot. Nothing moves on until you say so.

  1. 01 · Idea~2 min

    Pick an idea

    Type a topic or roll the dice. Five ideas arrive one by one, each with a hook, a twist and the real fact behind it, marked “verify”.

  2. 02 · Script~4 min

    Approve the script

    Narration paced for the length you chose, numbers spelled out for the voice. Click any line to rewrite it; the coloured words become the caption highlights.

  3. 03 · Storyboard~5 min

    Check the storyboard

    One real frame per shot, rendered from the scene code, so you see the actual video before a single word is voiced.

  4. 04 · Voice~1 min

    Hear the voice

    With an ElevenLabs key, every line is voiced and stitched to its neighbours, and the cut re-times itself to the real voice. No key yet? A labelled placeholder voice keeps you moving.

  5. 05 · Render~4 min

    Download the short

    A full-quality MP4, a lighter phone copy (24 MB in our run), a cover frame and three titles of 60 characters or fewer, ready to post.

The app

A calm studio, not a chat box.

No prompts to write, no settings to tune. The skills, the prompts and the model choices are built in, and a live activity feed shows what Claude reads, writes and runs.

127.0.0.1:4317

Your machine. Your login.

It talks only to the services you connect.

  • Runs on 127.0.0.1 only. A private link with a one-time token; nobody else on the network can open it.
  • Uses your own Claude Code. Studio Gen drives the copy that is already signed in. It never reads, copies or stores your login or tokens.
  • Runs on your plan's usage. No API key needed: runs count toward your Claude plan's usage limit, and the cost meter is an estimate, not a charge.
  • Keys stay in memory. Paste an ElevenLabs key and it is never written to disk.
  • Safe advice only. Topics and scripts are checked for unsafe content, and every fact is flagged “verify”.

Quick start

Running in five minutes.

You need Node.js 20+ and Claude Code signed in to your Claude account. An ElevenLabs key is optional.

  1. 1

    Get the code

    git clone https://github.com/Liam64k/Hackathon-claude-vid-gen.git
    cd Hackathon-claude-vid-gen

    Or download the ZIP from GitHub (green “Code” button) and open a terminal in that folder.

  2. 2

    Install, once

    npm ci --ignore-scripts
    npx remotion browser ensure

    Installs the packages without running install scripts, then downloads the headless browser that renders the video.

  3. 3

    Check your setup

    npm run doctor

    A pass/fail table that tells you exactly how to fix anything missing.

  4. 4

    Start the studio

    npm start

    On Windows you can just double-click Start Studio.cmd. No Claude account handy? npm run demo plays the whole flow from recorded runs, offline and free.

Questions

Before you start.

Does it cost anything?

Studio Gen is free. It runs on the Claude plan you already have: each run counts toward your plan's usage limit, not your card. The dollar figure in the app is the API-equivalent estimate that Claude reports, labelled “not billed”. A full video used about $2.60 of that estimate in our test (plus $0.24 for the optional fact check). ElevenLabs has a free plan; see the next question for its rules.

Can I post the videos?

Yes, they are yours. Check the facts marked “verify” before you publish. If you use ElevenLabs' free plan, it is non-commercial and published videos must credit “elevenlabs.io” in the title (check ElevenLabs' current terms); Studio Gen adds that credit to the titles it writes for you.

What kinds of videos can it make?

Narrated survival and “what would you do?” shorts, from 20 to 180 seconds, for TikTok, Shorts, Reels, YouTube and square or 4:5 feeds. The first art pack, Winter Lake, draws the scenes; more packs and looks are on the way.

Is this a website I sign up for?

No. Studio Gen is an app you download and run on your own computer. There is no account, no server of ours and no analytics or tracking. This page is the only part that lives on the web, and it loads nothing from third parties.

Which computers does it run on?

It was built and tested end to end on Windows 11 with Node.js 20 or newer. macOS and Linux paths are written but untested so far. Plan for about 2 GB of free disk (packages plus Remotion's ~120 MB headless browser and your renders).

What if I hit my usage limit mid-video?

The step pauses and keeps everything it has done so far. Resume it after your limit resets. Voice clips that are already made are reused, never billed twice.
